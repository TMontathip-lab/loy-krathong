เว็บไซต์ลอยกระทงออนไลน์ โรงเรียนบ้านวังตะโก — เพิ่มเพลงและไอคอน

1) ใช้โค้ด index.html, style.css, app.js, asset-masks.js วางไว้ที่ระดับแรกของโฟลเดอร์เว็บไซต์
2) นำไฟล์ทั้งหมดใน assets/ ที่ให้มาไปไว้ใน assets/ ที่มีภาพกระทง PNG เดิมครบ 23 รูป
3) นำ manifest.webmanifest ไปไว้ข้าง index.html
4) เปิด index.html ใน Chrome / Safari หรือเผยแพร่กับ GitHub Pages
5) กดปุ่ม “เปิดเพลง” ที่ส่วนหัวเพื่อฟังดนตรีวนซ้ำ แล้วกด “ปิดเพลง” เพื่อหยุด

ข้อควรทราบ
- เบราว์เซอร์ไม่อนุญาตให้เปิดเสียงเองโดยไม่ผ่านการแตะหรือคลิก ปุ่มเพลงจึงเริ่มต้นในสถานะปิด
- เพลงบรรเลงเล่นวนซ้ำต่อเนื่องขณะเปลี่ยนหน้าในเว็บ (SPA)
- ไอคอนใช้รูป Icon.png ที่ผู้ใช้ส่งมา ทั้งส่วนหัว แท็บเบราว์เซอร์ และไอคอนบนมือถือที่รองรับ
- ก่อนเผยแพร่เพลงบนเว็บไซต์สาธารณะ ต้องตรวจสอบสิทธิ์ใช้งานเพลง PJJohan ให้เรียบร้อย
- เวอร์ชันนี้ยังเป็นตัวอย่างทดลอง ไม่เชื่อม Firebase
